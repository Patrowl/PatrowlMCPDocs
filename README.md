# PatrowlMCP Starter Kit

Static site published at <https://mcp.help.patrowl.io> with GitHub Pages (branch `main`, root folder).

- `index.html`: the whole page (styles, 8-language i18n data and script are inline)

Preview locally: `python3 -m http.server` and open <http://localhost:8000>.
